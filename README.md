# Бот-напоминатель для группы ДГТУ

![alt text](image.png)

Бот получает актуальное расписание для конкретной группы из публичного API ДГТУ и отправляет в заданную Telegram-группу:

- напоминание за 20 минут до каждой пары;
- предмет, преподавателя и время;
- аудиторию крупно и отдельно: `📍 АУДИТОРИЯ: ...`;
- полное расписание на день в 07:30 (МСК), а если занятий нет — сообщение «сегодня пар нет, отдыхаем».
- сообщение с актуальными данными сразу после изменения, добавления или отмены пары.

Он проверяет расписание каждые 30 секунд и сохраняет уже отправленные сообщения, поэтому после перезапуска не создаёт дубли.

## Настройка

Все параметры находятся в `.env`. По умолчанию настроена группа ВИС23 (`GROUP_ID=73001`), московское время, интервал из `REMINDER_MINUTES` и утреннее расписание в 07:30. При необходимости время утреннего сообщения можно задать переменными `DAILY_SCHEDULE_HOUR` и `DAILY_SCHEDULE_MINUTE`. Переменная `SEND_DAY_OFF_MESSAGE=false` отключает утреннее сообщение в дни без пар.

Источник расписания: [ДГТУ — Нужная группа](https://lk.donstu.ru/WebApp/#/Rasp/Group/73001).

# Как используется мною и почему создан?

Подключена собственная группа и используется для уведомления однокурсников. Создана для того, чтобы экономить время студентов. Так как заходить каждый раз на сайт ДГТУ намного медленее чем просто получить уведомление о следующей паре.
