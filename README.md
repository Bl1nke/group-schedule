# Бот-напоминатель для группы ДГТУ

![alt text](image.png)

Бот получает актуальное расписание для конкретной группы из публичного API ДГТУ и отправляет в заданную Telegram-группу:

- напоминание за 20 минут до каждой пары;
- предмет, преподавателя и время;
- аудиторию крупно и отдельно: `📍 АУДИТОРИЯ: ...`;
- сообщение «сегодня пар нет, отдыхаем» в 08:00 (МСК), если занятий нет.

Он проверяет расписание каждые 30 секунд и сохраняет уже отправленные сообщения, поэтому после перезапуска не создаёт дубли.

## Первый запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте его токен.
2. Добавьте бота в нужную группу.
3. Напишите в группе `/chatid` и скопируйте полученный ID.
4. Скопируйте `.env.example` в `.env` и внесите токен и ID.
5. Запустите один из вариантов ниже.

### Через Docker

```powershell
docker compose up -d --build
```

### На компьютере с Python 3.11+

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python bot.py
```

Для постоянной работы разместите папку на сервере или устройстве, которое не выключается. Docker Compose автоматически перезапустит бота после сбоя или перезагрузки.

## Настройка

Все параметры находятся в `.env`. По умолчанию настроена группа ВИС23 (`GROUP_ID=73001`), московское время и 10 минут до пары.

Источник расписания: [ДГТУ — Нужная группа](https://lk.donstu.ru/WebApp/#/Rasp/Group/73001).

# Как используется мною и почему создан?

Подключена собственная группа и используется для уведомления однокурсников. Создана для того, чтобы экономить время студентов. Так как заходить каждый раз на сайт ДГТУ намного медленее чем просто получить уведомление о следующей паре.
